# steam-market-api

steam-market-api is a simple go project. It is a small package that provides Steam Market API client.

## Installation

```bash
go get github.com/olexandrf/steam-market-web-api
```

## Usage

```go
// import package 
import (
    "github.com/olexandrf/steam-market-web-api/steam/market"
    "github.com/olexandrf/steam-market-web-api/steam/web"
)
```
